# 小微企业管理助手

专为小微企业设计的极简人事管理与专业财务管理工具。

## 功能特性

### 人力资源（极简版）
- 👥 员工花名册：增删改查、批量导入
- 📅 考勤打卡：签到/签退、考勤查询
- 💰 工资表生成：自动计算出勤天数与实发工资

### 财务管理（专业版）
- 📒 记账管理：科目管理、凭证录入、试算平衡
- 📄 发票管理：销项/进项发票、认证管理、统计
- 📊 税务报表：增值税月报、企业所得税季报、个人所得税
- 📈 财务报表：资产负债表、利润表、现金流量表
- 📆 税务日历：自动生成申报截止日期、到期提醒

## 技术架构

- **前端框架**: Vue 3 + TypeScript + Element Plus
- **桌面框架**: Tauri 2.x
- **后端语言**: Rust
- **本地数据库**: SQLite
- **图表库**: ECharts
