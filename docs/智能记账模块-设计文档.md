# 智能记账模块 · 设计文档

> 版本：v1.0（阶段一实施中）
> 适用：小微企业管理助手（Tauri + Rust + Vue 3 + SQLite）

## 1. 目标

在凭证录入中提供“智能录入”模式：用户用自然语言描述日常业务（如“今天收取服务费 100 元”“昨日购买原材料 80 元”），系统自动识别日期、金额、业务类型与结算方式，生成正确的借贷分录，经用户预览确认后入账。一段描述含多笔业务时，按笔拆成多张凭证。

## 2. 商业化与授权（已定）

| 项 | 决策 |
|---|---|
| 商业模式 | 买断（永久可用），建议含 1 年规则包/版本更新 |
| 模块形态 | A 方案：解析引擎内置主程序，按授权启用；规则包/模型可在线下发 |
| 授权交付 | 授权码/卡密，**联网兑换一次**后离线使用 |
| 授权校验 | Ed25519 签名 License，App 内置公钥离线验签；Rust 命令层为权威开关 |
| 默认口径 | 金额含税、面向小规模纳税人 |
| 免税 | 小规模月/季销售额阈值可配，自动提示“免税/计税” |
| 多笔 | 一段话多笔 → 多张凭证 |
| LLM | 允许云端，默认关闭，需显式同意；规则优先、LLM 兜底 |
| 学习 | 记录“原文→确认后的分录”，沉淀为候选模板，用户一键采纳 |

## 3. 授权码与买断流程

### 3.1 角色
- 应用平台：收款、发卡密或订单回调。
- 授权服务器（厂商）：保存 Ed25519 私钥，根据订单签发 License Token。
- 客户端：内置公钥，离线验签并解锁模块。

### 3.2 流程
1. 用户在平台付费购买“智能记账·永久版”。
2. 平台发放授权码（卡密），或回调授权服务器。
3. 用户在 App「模块中心」输入授权码，**联网兑换一次**：
   - 客户端把授权码提交授权服务器；
   - 服务器校验订单后，返回**签名后的 License Token**；
   - 客户端用内置公钥验签，写入本地 `smart_entitlement`，模块解锁。
4. 之后**完全离线可用**。
5. 支持导入离线 License 文件（无网场景）。

### 3.3 License Token 格式
```
SV1.<base64url(payload_json)>.<base64url(ed25519_signature(payload_bytes))>
```
payload 示例：
```json
{
  "product": "smart_voucher",
  "license_id": "SV-20261010-0001",
  "customer": "北京希北科技有限公司",
  "edition": "perpetual",
  "perpetual": true,
  "features": ["smart_voucher"],
  "updates_until": "2027-10-10",
  "issued_at": "2026-10-10T12:00:00Z",
  "nonce": "防重放"
}
```
校验项：签名有效、`product=smart_voucher`、`features` 含 `smart_voucher`、`perpetual=true` 或未过期。

## 4. 规则包与加载（A 方案）

- 规则包为**纯数据**（场景模板 + 别名 + 税率/免税参数 + prompt 模板），JSON 形式。
- 安装包内置一份基础规则包，保证购买/激活后**开箱即用、离线可用**。
- 可选在线下发更新：下载到临时目录 → 校验签名与 hash → 原子替换 → 更新 `current.json`；失败回滚。
- 加载优先级：内置包 < 已下发包（同 id 覆盖）< 用户自定义场景 < 学习样本打分。

## 5. 场景模板（完整）

```json
{
  "id": "purchase_material",
  "name": "购买原材料",
  "version": 1,
  "keywords": ["原材料", "材料", "原料"],
  "direction": "out",
  "category": "purchase",
  "amount_tax": "inclusive",
  "tax": { "mode": "input", "deductible": { "general": true, "small": false }, "rate_source": "vat_rate" },
  "settlement": [
    { "when": ["未付", "赊", "欠款"], "account": "2202" },
    { "when": ["现金"], "account": "1001" },
    { "default": "1002" }
  ],
  "entries": {
    "general": [
      { "side": "debit",  "account": "1403", "amount": "net" },
      { "side": "debit",  "account": "2221", "amount": "tax" },
      { "side": "credit", "account": "{{settlement}}", "amount": "total" }
    ],
    "small": [
      { "side": "debit",  "account": "1403", "amount": "total" },
      { "side": "credit", "account": "{{settlement}}", "amount": "total" }
    ]
  }
}
```

- `amount`：`total` / `net`（=total/(1+rate)）/ `tax`（=total−net）。
- 小规模纳税人：**进项不抵扣**，采购全额入成本；销售按征收率拆“应交税费—应交增值税”。
- 结算分支：现金→1001，银行/转账→1002，未付/赊→应付账款 2202。

## 6. 解析流水线

1. 归一化：全半角、中文数字、相对日期（今天/昨天/前天/本周X）。
2. 切分子句（，。；、换行、以及/另外）→ 每笔一张凭证。
3. 抽取：日期、金额、方向、结算方式、业务关键词。
4. 场景匹配：内置+自定义+别名，按优先级/学习样本打分。
5. 税额：纳税人类型 + 含税 + 税率 + 免税阈值。
6. 渲染分录并校验（平衡、科目方向、金额>0）。
7. 置信度与需澄清项。
8. 规则失败且已开启 → LLM 兜底；否则回退手工。

## 7. 小规模 / 含税 / 免税口径

- 销售（含税）：`收入 = 总额/(1+征收率)`，`应交增值税 = 总额−收入`；征收率默认 3%，可配 1%。
- 采购/费用：价税合计全额入成本，不拆进项税。
- 免税提示：按期间累计销售额判断小规模免税额度（默认月 10 万 / 季 30 万，可配）；未超提示“可免税”（不拆销项税），已超按征收率计税。
- 已登记发票时优先使用发票税率/税额。

## 8. 数据表（新增）

```sql
CREATE TABLE smart_entitlement (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  license_token TEXT,
  payload_json TEXT,
  activated_at TEXT,
  updates_until TEXT
);
CREATE TABLE smart_scenarios (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  scenario_id TEXT NOT NULL UNIQUE,
  name TEXT NOT NULL,
  definition TEXT NOT NULL,
  is_builtin INTEGER NOT NULL DEFAULT 0,
  enabled INTEGER NOT NULL DEFAULT 1,
  priority INTEGER NOT NULL DEFAULT 100,
  created_at TEXT, updated_at TEXT
);
CREATE TABLE smart_learning_samples (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  raw_text TEXT NOT NULL,
  scenario_id TEXT,
  entries TEXT NOT NULL,
  adopted INTEGER NOT NULL DEFAULT 1,
  created_at TEXT
);
```

## 9. 接口（Tauri commands）

- `smart_module_status() -> {entitled, edition, updates_until, licensed}`
- `smart_activate_code(code) -> status`（验签、写入、解锁）
- `smart_import_license(token) -> status`（离线导入）
- `smart_scenarios_list()` / `smart_scenario_save(def)` / `smart_scenario_delete(id)`
- `smart_parse(text, date) -> {drafts: [...], notes}`
- `smart_commit(drafts) -> [voucher_no]`

## 10. 前端交互

- 「模块中心」：显示模块状态、授权码输入/兑换、License 导入、更新到期日。
- 「智能录入」：多行文本 + 日期；解析后展示多张凭证草稿（借贷、科目、金额、置信度、提示）；用户确认后批量提交。

## 11. 分期

- 阶段一（本次）：授权码离线验签、场景模板（内置+自定义）、规则解析（小规模含税+免税提示）、多张凭证、预览确认、学习样本记录。
- 阶段二：规则包在线下发/更新、模块中心完善、学习候选模板。
- 阶段三：LLM 兜底、sidecar（如确需）。

## 12. 安全与风险

- 客户端买断无法绝对防破解；靠逐客户签名 License + Rust 层校验 + 混淆 + 更新走服务器提高门槛。
- 财务数据敏感：LLM 默认关闭、需显式同意、脱敏。
- 小规模免税/征收率政策会变，全部走配置。

## 13. 密钥管理

- 授权服务器持有 Ed25519 私钥，仅在签发时使用，绝不入库/发版。
- 客户端只内置公钥。
- 签发工具见 `tools/mint_license.py`（读取环境变量中的私钥）。
